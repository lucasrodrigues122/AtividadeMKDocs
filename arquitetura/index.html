    Arquitetura do Sistema - Petshop genérico (C4 Model)

    Este documento descreve a arquitetura de software do sistema Petshop genérico utilizando os dois primeiros níveis de abstração do C4 Model.

    Nível 1: Diagrama de Contexto

    O Diagrama de Contexto apresenta a visão macro do Petshop genérico, mapeando os usuários que interagem com a plataforma e os serviços externos integrados.

    Atores (Usuários)

    • Tutor de Pet ([Pessoa]): Cliente da clínica. Acessa a plataforma para agendar consultas, visualizar histórico de vacinas e efetuar pagamentos.
    • Médico Veterinário ([Pessoa]): Profissional de saúde. Gerencia prontuários médicos, agenda de atendimentos e emissão de exames/prescrições.

    Sistema Central

    • Petshop genérico ([Sistema de Software]): Plataforma para gestão de clínicas veterinárias, agendamento de serviços, prontuário eletrônico e acompanhamento de vacinação.

    Sistemas Externos

    • Gateway de Pagamento ([Sistema Externo]): Serviço responsável pelo processamento de pagamentos via PIX e Cartão de Crédito.
    • Serviço de Mensageria ([Sistema Externo]): API de terceiros (ex: WhatsApp/SMS) responsável pelo envio de lembretes de consultas e alertas de vacinação.

    Relacionamentos e Protocolos

    Origem Destino Descrição / Protocolo
    Tutor de Pet Petshop genérico Agenda consultas e efetua pagamentos [HTTPS]
    Médico Veterinário Petshop genérico Registra prontuários e gerencia consultas [HTTPS]
    Petshop genérico Gateway de Pagamento Processa transações financeiras [REST / HTTPS]
    Petshop genérico Serviço de Mensageria Solicita envio de notificações e lembretes [REST / HTTPS]
    Serviço de Mensageria Tutor de Pet Entrega lembretes via WhatsApp/SMS [Assíncrono]

    Nível 2: Diagrama de Containers (Containers)

    O Diagrama de Containers detalha as aplicações, APIs e banco de dados que compõem o Petshop genérico.

    Containers Internos

    1. Mobile App (Tutor) ([Container: Flutter / Mobile]):
    2. Interface móvel utilizada pelos tutores para acompanhamento de saúde do pet, histórico de vacinas e solicitações de agendamento.
    3. Portal Web (Clínica) ([Container: React.js / SPA]):
    4. Aplicação web utilizada pela equipe veterinária e recepção para controle de agenda e gestão de prontuários eletrônicos.
    5. API Backend ([Container: Java 17 / Spring Boot]):
    6. API REST central responsável pelo processamento das regras de negócio, autenticação, agendamentos e prontuário eletrônico.
    7. Banco de Dados ([Container: PostgreSQL]):
    8. Banco relacional para armazenamento persistente dos dados de usuários, pets, consultas, prontuários e histórico de vacinas.
    9. Serviço de Fila de Notificações ([Container: Redis / Worker]):
    10. Armazenamento em memória para gerenciamento assíncrono do envio de lembretes de consultas e vacinas.

    Comunicação entre Containers

    Origem Destino Descrição / Protocolo
    Mobile App API Backend Requisições de agendamento e perfil [JSON / HTTPS]
    Portal Web API Backend Requisições de prontuário e gestão [JSON / HTTPS]
    API Backend Banco de Dados Leitura e escrita de dados [JDBC / SQL]
    API Backend Serviço de Fila Enfileiramento de lembretes [Redis Protocol]
    API Backend Gateway de Pagamento Processamento de cobranças [REST / HTTPS]
    Serviço de Fila Serviço de Mensageria Disparo de mensagens externas [REST API]
